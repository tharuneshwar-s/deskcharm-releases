Windows says "Windows protected your PC"

DeskCharm isn't code-signed yet, so Windows SmartScreen warns about the installer the first time. It's safe to continue:

Illustration, not a real screenshot. Click More info → Run anyway. It installs for your account only (no admin needed) and starts in the system tray; left-click the tray icon for Settings.

Want to check the file? Each release lists the installer's SHA-256 checksum. In PowerShell run Get-FileHash .\DeskCharm_*_x64-setup.exe and compare it with the one on the release page. Only download DeskCharm from deskcharm.in or its GitHub releases page.

Trying it on macOS

The macOS build is untested and not notarized by Apple. Drag DeskCharm to Applications, then right-click it → Open → Open. Please tell us what works and what doesn't.

Trying it on Linux

The Linux build is untested. You need a system tray (on GNOME, the AppIndicator extension). On Wayland, always-on-top transparent windows are limited — if the charm misbehaves, log in with an X11 session.

Found a problem? Open an issue on GitHub or email support@deskcharm.in.

Questions

Is it really free?

Yes. The charm, all visitors and every calm tool are free, with no ads. DeskCharm Pro is a one-time lifetime licence: ₹69 for launch, then ₹99. Every install gets all of Pro free for 7 days. Calm tools never move behind it.

Does DeskCharm send my data anywhere?

No. There's no account, analytics or tracking. It goes online only to check GitHub for updates, and for live weather or calendar quiet if you turn those on. Details are in the guide.

Can I use it in Tamil?

Yes. Settings → General → Language → Charm & visitors speak: English or தமிழ். The speech bubbles and cues change; the Settings window stays in English.

How do I open Settings?

Left-click the DeskCharm icon in the system tray. Right-click the charm itself for breathing, focus, Today, Hide and Mute.

Can I click things underneath it?

Yes. Clicks go straight through everywhere except on the charm and visitors.

Will it show up when I share my screen?

Not by default — the charm is excluded from screen sharing, recordings and screenshots, and it hides during fullscreen apps and calls. You can change this in Settings → Privacy.

How do I get new versions?

DeskCharm checks for updates every few hours and installs a new version with one click (Settings → General → Updates).

Does it work on macOS or Linux?

DeskCharm is built for Windows. macOS and Linux builds exist but are untested, and some features (music sway, smart hiding, screen-share invisibility) are Windows-only.

How do I uninstall it?

Windows Settings → Apps → DeskCharm → Uninstall. This also removes your settings and insights.
